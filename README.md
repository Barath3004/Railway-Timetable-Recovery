# Railway Resource Disruption-Aware Timetable Recovery

## Project Overview

This project is a Final Year B.Tech AI & Data Science project that focuses on recovering railway timetables after operational resource disruptions such as track failures, signal failures, and platform closures.

Instead of only minimizing train delays, the proposed system also considers passenger disruption while satisfying railway operational constraints.

The system serves as a Human-in-the-Loop Decision Support System, where railway operators are presented with multiple feasible recovery plans generated using Adaptive Large Neighborhood Search (ALNS).

---

## Project Objectives

- Recover railway timetables after resource disruptions.
- Minimize total train delay.
- Minimize passenger disruption.
- Ensure all operational constraints are satisfied.
- Provide multiple feasible recovery plans for railway operators.
